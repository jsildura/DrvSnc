# Extension Icons

Place your extension icons here with the following sizes:

- `icon16.png` - 16x16 pixels (toolbar)
- `icon32.png` - 32x32 pixels (toolbar retina)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Design Guidelines

- Use Google Drive-inspired colors (blue, yellow, green)
- Include a cloud upload symbol
- Maintain consistency across sizes
- Follow Material Design icon principles
- Ensure readability on light and dark backgrounds

## Quick Generation

You can use online tools to generate icons:
- [Figma](https://figma.com)
- [Canva](https://canva.com)
- [GIMP](https://gimp.org)

Or use an AI image generator with the prompt:
"Material Design icon for Google Drive upload extension, cloud with arrow, colorful, 128x128 pixels, transparent background"
